# Documentation

This folder keeps non-runtime project material out of the repository root.

- `demo/`: demonstration scripts and product-highlight notes
- `planning/`: sprint and product planning notes
- `thesis/`: research and software-copyright preparation notes
- `dev/`: developer maintenance notes and legacy agent handoff notes
- `deployment/`: server migration and deployment handoff guides
- `assets/`: README screenshots, design figures, and source persona/teaser media
- `LIVETALKING_INTEGRATION.md`: notes for the LiveTalking avatar integration
